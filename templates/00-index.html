Twelve templates covering the quarterly, everyday correspondence and the full event cycle. Two versions of everything

PREVIEW is the approval copy. Real CCC content, filled in, ready to put in front of Chris. Every event, speaker and sponsor in it is genuine, taken from CCC's own sends and the live site.

TEMPLATE is the working file, with {{TOKENS}} where the content goes. This is the one that gets edited and sent.

Each preview is generated from the template beside it by fill-mock.mjs. Change a layout in the template and re-run node fill-mock.mjs to bring the previews back in step. Never hand edit a -preview.html, it gets overwritten.

Still needed from Chris before anything sends

His email address. The mocks show chris@contractorsclosersconnections.com, which is a guess. One find and replace across the folder fixes it everywhere.

Speaker headshots. Every speaker slot is a placeholder card. Real ones want to be 260 by 400 and converted to greyscale, matching the site.

Sponsor logos. Same. The platinum slots are white placeholder cards sized 240 by 100. The firm names in the mocks are CCC's real partners, so the list is right, only the artwork is missing.

Numbers. Attendance figures, ticket prices, seat counts and the quarterly stat strip are illustrative. They are the only invented content in the approval set and are flagged in fill-mock.mjs.

How the templates work

Every editable value is a token in double braces, for example {{EVENT_NAME}} or {{FIRST_NAME}}. Open the file in any text editor, replace the tokens, and paste the result into the code view of whatever sends the mail. {{FIRST_NAME}} should be swapped for the merge field the platform uses rather than a literal name.

Images are already hosted on GitHub Pages. Do not re-upload them into the email platform's own media library, because that puts the assets somewhere CCC does not control.
